GraphQL: Syntax Highlighting

Les typedefs

Les typedefs du serveur définissent tous les types et requêtes qui peuvent être utilisés.

export const typedefs = `#graphql

    type Query {
        games: [Game!]!
    }
    
    type Game {
        id: ID!
        title: String!
    }
`

Les resolvers

Les "resolvers" sont les fonctions qui récupèrent ou modifient les données.

export const resolvers = {
    Query: {
        games: () => {
            return [{ id: "1", title: "Celeste" },]
        }
    }
}

Les mutations

Les mutations sont les requêtes qui permettent d'ajouter, modifier ou supprimer des données.

type Mutation {
    ajoutLivre(livre: AjoutLivreInput): ID!
}

input AjoutLivreInput {
    titre: String!
    auteur_id: ID
}

Exemple Javascript

Exemple pour récupérer des données GraphQL avec Javascript

async function graphql(url, query, variables = {}) {
    const response = await fetch(url, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ query, variables })
    })

    const json = await response.json()

    return json
}
