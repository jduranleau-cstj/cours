JWT

Refresh token

Un "access token" JWT a habituellement une courte durée de vie.

Lors de la connexion, on envoie aussi un deuxième token (refresh token) qui permet de récupérer un "access token" neuf sans se reconnecter.

Les "refresh tokens" sont sauvegardés dans la base de données.

OAuth2

OAuth2

Contrairement à JWT qui représente seulement le token lui-même, Oauth2 est une structure d'authentification.

  • Gestion des authenfications (souvent avec des JWT)
  • Gestion des permissions
  • Authentification sur un partie-tiers
