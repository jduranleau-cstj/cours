GraphQL

GraphQL

GraphQL représente une façon unifiée d'accéder à des données à l'aide d'une API.

  • Il s'agit donc d'une alternative à REST
  • Créé par Facebook en 2012 et open-source depuis 2015

Documentations

La documentation de GraphQL est excellente!

https://graphql.org/

Pour l'utilisation avec Javascript: https://www.graphql-js.org/

Nomenclature

  • Schema: Structure typée et relations des données
  • Query: Récupération de données (read)
  • Mutation: Modification (insert, update, delete)

REST

GET /posts

Suivi d'un appel par post à:

GET /post/{x}/comments?qty=3

GraphQL

POST /graphql

Body du POST:

query {
    posts {
        title
        comments(qty: 3) {
            author,
            text
        }
    }
}

Types disponibles

String, Int, Float, Boolean et ID

Quelques "modificateurs":

  • [Int] : Array de Int
  • Int! : Int non null
  • [Int!]! : Array non null de Int non null

Et quelques autres types plus obscurs

GraphiQL et

Prononcé "graphical", GraphiQL est un outil qui:

  • Génère la documentation d'un "Schema" GraphQL
  • Offre un éditeur de requête avec autocomplétion
  • Exécute les requêtes avec une console de résultat


Apollo est un autre système du même style.
