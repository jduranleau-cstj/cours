Révision: Client et serveur

Révision: API, REST et CRUD

Une API permet à deux logiciels différents de se parler et d'échanger des données.

REST est une méthode standardisée pour construire une API. Cette méthode est le standard du Web.

CRUD est l'acronyme pour Create, Read, Update et Delete. Ce sont les 4 actions fondamentales d'une API REST.

Révision: CORS

CORS: Cross-Origin Resource Sharing

Pour un serveur, le CORS permet d'autoriser une application ou un site Web d'un parti tiers à accéder aux données.

Types d'applications Web

  • SSR (Server Side Rendering): Exécution de code côté serveur pour créer le HTML. Par exemple PHP ou C#.
  • CSR (Client Side Rendering): Exécution de Javascript qui modifie le HTML suite à des requêtes d'API. Par exemple React et Vue.
  • SPA (Single Page Application): Une forme de CSR qui ajuste l'entièreté de son contenu pour simuler des pages.
  • PWA (Progressive Web App): Une forme de site Webs auquels sont données des comportements similaires à une application native et qui peut s'ajouter sur l'écran d'accueil d'un mobile.
