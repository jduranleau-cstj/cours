Exercice - Cours 1

Mise en situation

Vous devez créer un site Web et une application mobile qui permet d'afficher une image de chat aléatoire.

Exemples d'interactions:

  • Un utilisateur navigue jusqu'au site Web dans son navigateur. La page qui lui est présentée affiche une image de chat aléatoire.
  • L'utilisateur vote de façon positive ou négative pour l'image. Le score de l'image est présent à proximité des boutons de vote.
  • L'utilisateur ajoute une nouvelle image à la liste d'images possibles en indiquant l'URL de l'image à ajouter dans un petit formulaire.

Vous devez:

  • Créer un mock de l'API que vous devrez créer pour ce projet.
  • Créer les requêtes dans Bruno afin d'avoir une façon de tester l'ensemble des requêtes.
  • Créer la véritable API en PHP (avec ou sans Laravel).
  • Créer un site Web qui utilise JavaScript pour récupérer et envoyer les données à l'API.

Vous pouvez vous placer en équipe.

Vous pouvez aussi utiliser l'IA pour vous guider, mais pas pour générer le projet.

Déjà fini? Voici quelques idées d'ajouts.

  • Une page avec l'ensemble des images en ordre des plus appréciées.
  • Une page admin pour supprimer des images.
  • Sur la page d'accueil, limiter les images montrées à celles ayant plus de -5 comme score.
