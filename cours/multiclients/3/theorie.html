Json Web Token (JWT)

  • Standard officiel
  • Utilisé pour l'authentification et les autorisations
  • Autonome (self-contained): Pas besoin de base de donnée pour valider le token

Source: https://logto.io/jwt-decoder

Structure d'un JWT

Header: Contient le type de jeton et l'algorithme de signature utilisé.

Payload: Contient les "claims" (données).

Signature: Assure l'intégrité du message en combinant le header encodé, le payload encodé et une clé secrète connue uniquement du serveur.

Liste de "claims" standardisées

  • iss: Nom du serveur (Issuer)
  • exp: Date d'expiration
  • iat: Date de création (Issued At)
  • jti: Identifiant unique du token (JWT ID)

Transfert du token

Habituellement, le token est envoyé en header HTTP avec la requête.

JS (envoi): 

"Authorization": "Bearer le.JWT.ici"

PHP (réception): 

$headers = getallheaders();
