Exercice - Cours 3

Dans le contexte de notre API JWT, ajoutez les fonctionnalités suivantes:

  • Ajouter une sauvegarde du token lors de la connexion et son chargement au début de la page. Une solution possible serait localStorage.
  • Ajouter un rôle au token selon l'utilisateur qui se connecte. Une API d'information doit ensuite être ajoutée et être accessible par l'admin seulement. Les autres APIs peuvent être accédées par un utilisateur OU un admin.
  • À l'aide de recherches, tentez une implémentation du refresh token.
