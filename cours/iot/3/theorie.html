Variables (un rappel)

Il est possible d'utiliser des variables "permanentes".

  • context : Local au node lui-même
  • flow : Local au flow
  • global : Global pour l'ensemble des flows

Par exemple:

flow.set("compteur", 123)
flow.get("compteur")

Node "Link"

Le node "link" permet de transporter un message à un autre endroit arbitraire. Possiblement même dans un autre flow!

Il est important de toujours bien nommer ces nodes pour s'y retrouver.

Node "Text"

Comme l'indique sa documentation, le node "text" permet aussi d'afficher du HTML.

On peut le combiner à un node "template" pour créer des images ou autres balises.

Configuration de node dynamique

Plusieurs configuration de nodes peuvent être changées pendant l'exécution

Pour les changer, on envoie un message avec la clé ui_update et les valeurs à changer.
