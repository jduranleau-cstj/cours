Node-RED : Mise en page

La mise en page de Node-RED dashboard utilise le principe de "grid" CSS.

On peut accéder à un outil pour visualiser la grille de composantes.

Node-RED : Mise en page

Une fois modifié, il faut sauvegarder les modifications et faire un merge dans l'interface de d'édition.

VueJS avec Node-RED

En utilisant le node "template" du dashboard, on peut:

  • Styliser du HTML avec CSS
  • Modifier le HTML avec un payload
  • Réagir aux payload avec JS
<template>
    <h1>Un titre stylisé</h1>
</template>

<style>
    h1 {
        color: red;
    }
</style>

Contrôle du payload avec JS

<template>
    <div>
        <p>Payload: {{ msg.payload }}</p>
    </div>
</template>
<script>
export default {
    data() {
        return {}
    },
    watch: {
        msg: {
            handler(m) {
                // Dans la console du site Web
                console.log(m)
            },
        }
    },
    methods: { },
}
</script>
