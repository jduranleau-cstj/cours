Exercices - Cours 1

  1. Faire clignoter une LED un certain nombre de fois et à une vitesse paramétrable. Idéalement sous la forme d'une fonction appelée dans main.

    Afficher le signal SOS avec la LED.

  2. Afficher la valeur d'un potentiomètre avec le Serial. Normaliser cette valeur entre 1 et 100.
  3. En utilisant un potentiomètre, affichez le texte suivant avec un Serial print: --------------o-----. Le cercle devrait représenter la position du potentiomètre. Plus il est tourné, plus le "o" se déplace.
  4. Allumer une LED quand un bouton ou "Touch Sensor" est appuyé et l'éteindre lorsqu'il est relâché.
  5. Créer un jeu de réflexe. Lorsqu'une LED s'allume, l'utilisateur doit appuyer sur un touch le plus rapidement possible. On affiche dans le Serial la vitesse en millisecondes.
  6. Allumer une LED rouge lorsque le "Temperature Sensor" est à plus de 24°C (par exemple en le prenant dans vos mains et en soufflant doucement dessus).
  7. Allumer une LED seulement si les deux cas de figure suivants sont vrai:
    1. un "Light Sensor" est dans l'obscurité
    2. un "PIR Motion Sensor" détecte un mouvement

    La lumière doit alors restée ouverte pendant 3 secondes après le dernier déplacement

  8. Utiliser un "Sound Sensor" pour ouvrir les LEDs d'un LED Stick. Vous devrez utiliser la librairie "Adafruit_NeoPixel".
  9. Créez un code qui convertit un texte en code morse avec une LED.
