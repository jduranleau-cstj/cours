Exercices - Cours 9

  1. À l'aide de Node-RED, créez une route (API) qui permet d'afficher le dernier message reçu par MQTT sur le topic "cours9/message".

    Pour ce faire vous devrez d'abord sauvegarder dans une variable flow les messages reçus par MQTT.

    Ensuite avec les node HTTP, vous pourrez créer la route et fournir son message.

  2. Ajoutez au problème précédent le fait de sauvegarder chaque message à une base de données SQLite.

    Il vous faudra construire la requête SQL dynamiquement. Lisez bien la documentation du node pour les paramètres de requête préparés.

  3. Créez une page Web qui fait une requête fetch à Node-RED pour avoir la liste de tous les messages envoyés juqsu'à maintenant et sauvegardés dans la BDD.

  4. Finalement, ajoutez un bouton physique contrôlé par Arduino qui permet de détruire tous les messages sauvegardés dans la base de données.

    Il faudra envoyer la commande par MQTT!
