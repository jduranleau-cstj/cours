MQTT sur le Web

Il est possible d'établir une connexion a un broker par JavaScript.

Il faudra utiliser un Websocket puisque c'est en TCP et non HTTP.

On utilisa la librairie MQTT.js

  • Plus précisément ce fichier: mqtt.esm.js
import mqtt from "./mqtt.esm.js"

// "mqtt://piXX.local:9001" ou "mqtt://localhost:9001"
const client = mqtt.connect("mqtt:test.mosquitto.org:8081")

client.on("connect", () => {
    client.subscribe("mon/topic")
    client.publish("mon/topic", "Hello MQTT de JS")
})

client.on("message", (topic, message_buffer) => {
    const message = message_buffer.toString() // Converti le buffer en string JS
    console.log(`${topic}: ${message}`)
})
