Exercices - Cours 2

  1. Créer un flow qui injecte un message "Hello World" toutes les 5 secondes et l’affiche dans le debug panel.
  2. Envoyer un nombre avec inject, puis dans un node function, multiplier ce nombre par 2 avant de l’envoyer au debug.
  3. Toutes les 2 secondes, générer un nombre aléatoire entre 1 et 100, puis l’afficher dans la fenêtre de debug
  4. Convertir une valeur prédéterminée de Farenheit à Celcius. De plus, à l’aide du node Switch, afficher « Froid, tempéré ou chaud » dans la fenêtre Debug.
  5. À l'aide d'un inject, lancer le processus suivant.
    1. Générer un nom d'animal au hasard entre "chat", "chien", "poisson".
    2. Afficher le nom de l'animal dans le debug.
    3. Ajouter le mot "Un " devant le nom.
    4. Afficher le résultat dans le debug.
    5. Si le nom de l'animal commence par un "p", ajouter un "!" à la fin.
    6. Afficher le résultat dans le debug.

    Chacune de ces étape devrait être réalisée à l'aide d'un ou plusieurs node. Ne faites pas l'ensemble dans un node "Function"!

  6. À l'aide de trois inject différents qui représentent "roche", "papier" et "ciseaux", affichez le résultat d'une ronde de roche-papier-ciseaux contre un ordinateur dans le debug.

    Vous devez garder la logique en nodes autant que possible et limiter l'utilisation du node "function" à la création d'un random pour le tour de l'ordinateur.

  7. Un inject représente un lancé de dé à 20 faces. Le systèmes doit attendre deux lancé de dé et afficher le résultat le plus haut des deux.
  8. Créer une API HTTP GET avec un node http in qui retourne un JSON { titre: "Internet des objets", cours: 2 }
  9. Créer une page Web fournie par Node-RED qui affiche une image de chat aléatoire parmi plusieurs images possibles.
